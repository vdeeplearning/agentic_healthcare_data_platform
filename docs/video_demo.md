# Demo video production guide

Target: 4 minutes 45 seconds for a technical recruiter or hiring manager.

Use 1920×1080, 30 fps, browser zoom 100–110%, a clean desktop, and a cursor highlight no larger than 40 px. Record narration with a cardioid microphone 15–20 cm away in a quiet room; peak around −12 dB and remove long pauses rather than accelerating speech. Add burned-in or platform captions and export H.264 at 8–12 Mbps.

Open the architecture diagram, Streamlit demo, repository capability matrix, and verification page before recording. Use the [storyboard](video_storyboard.md), read the [script](video_script.md) conversationally, and complete the [capture checklist](video_capture_checklist.md).

## Backup strategy

Capture clean stills before recording. If a live click fails, pause, restore the deterministic question, and resume; use the still only as an honestly captured backup screen. Never imply optional PostgreSQL, Spark, Airflow, or Kubernetes runtimes executed if they did not.
