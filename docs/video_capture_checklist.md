# Video capture checklist

## Before recording

- Run the noninteractive smoke test, then start the full demo.
- Confirm API `/health` and Streamlit `/_stcore/health` return success.
- Close password managers, email, chat, terminals containing tokens, and unrelated windows.
- Clear the Streamlit API-key field and use deterministic curated questions.
- Preload diagrams and capability status; verify browser zoom and 1920×1080 canvas.
- Capture backup PNGs listed in `docs/demo.md`.

## During recording

- Keep the pointer away from text except when identifying a component.
- Pause half a second after each tab change.
- Do not scroll while speaking a dense sentence.
- Show the synthetic-data banner and verification qualifications.
- If a result differs unexpectedly, stop rather than narrating an unverified claim.

## Editing and export

- Remove installation waits and dead air; do not cut around errors in a misleading way.
- Normalize voice, reduce noise lightly, and keep music absent or below −30 dB.
- Add captions, chapter markers, repository URL, and alt-text summary.
- Export H.264 MP4, 1080p, 30 fps, 8–12 Mbps; review once without audio for visual clarity.
